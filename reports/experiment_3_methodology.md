# Experiment 3 Methodology

The experiment reused `reports/grouped_text_benchmark/splits/` exactly as saved. It did not recreate or alter splits. The seven labels were represented as multi-hot vectors. Model A used the cached `j-hartmann/emotion-english-distilroberta-base` at revision `0e1cd914e3d46199ed785853e12b57304e04178b` and threshold 0.35. Model B started from the same checkpoint, used a seven-output head with `BCEWithLogitsLoss`, and optimized only the classification head because full AdamW state exceeded available host memory. Configuration: seed 20261027, batch size 32, learning rate 2e-5, weight decay 0.01, max length 128, one epoch, CPU, no class weighting. Validation macro-F1 selected epoch and threshold; test was evaluated once afterward. Paired bootstrap used 2,000 sample-level resamples, seed 424242. Prediction artifacts include IDs and SHA-256 text hashes. Independent checks are in `research/experiment_3/verify_and_report.py`.
